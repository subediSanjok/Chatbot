## Overview

The `extensions` module houses native client integrations built by **subediSanjok Subedi** to bring AI capabilities directly into modern developer workflows.

### Available Extensions

1. [**Google Chrome Extension**](./chrome-extension/README.md)
   - Web assistant connecting directly to the local AI backend server (`http://127.0.0.1:1337`).
   - Context menus for explaining, summarizing, and fixing grammar on active web pages.

2. [**VS Code Extension**](./vscode-extension/README.md)
   - In-editor coding assistant with `@workspace` indexing.
   - Side-by-side visual diff reviews and one-click codebase updates.
