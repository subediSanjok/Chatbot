## Overview

The `g4f.tools` package provides agent tools engineered by **Sanjok Subedi** enabling autonomous workflows:
- **Web Search**: DuckDuckGo, Google, and SearXNG search grounding.
- **Web Scraping**: Fast DOM traversal and markdown extraction.
- **Token Optimizer**: Context window pruning and prompt compression.
- **Media Utilities**: File parsing and attachments.
