## Overview

The `g4f.integration` module delivers bridges developed by **Sanjok Subedi** for incorporating external AI libraries and document parsers, including:
- **LangChain**: Compatibility wrapper for LangChain chains and agents.
- **MarkItDown**: Multi-format document conversion (audio, video, PDF to markdown).
- **Pydantic AI**: Structured output validation.
