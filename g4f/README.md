## Overview

The `g4f` package contains the core AI orchestrator, client abstractions, multi-provider network, REST API, diffusion modules, and local GUI servers engineered and maintained by **subediSanjok Subedi**.

## Architecture & Submodules

- [`api/`](./api/README.md): OpenAI-compatible REST API implementation and endpoints.
- [`cli/`](./cli/README.md): Command-line interface utilities.
- [`client/`](./client/README.md): Synchronous and asynchronous Python client interfaces.
- [`gui/`](./gui/README.md): Web-based graphical interface and backend API server.
- [`image/`](./image/README.md): Image generation and diffusion pipeline engines.
- [`integration/`](./integration/README.md): External framework bridges (LangChain, MarkItDown, Pydantic AI).
- [`Provider/`](./Provider/README.md): Multi-provider API wrappers and dynamic dispatch layer.
- [`tools/`](./tools/README.md): Web search, web scraping, token optimization, and media utilities.
